# MunichStartupApp-BD2

**EXTRAORDINARIO - 2026 - PROYECTO FINAL**

## Sistema de Gestión de Munich Startup

Aplicación orientada a backend y modelo de datos para la gestión integral de startups, inversionistas y rondas de financiamiento, integrada con persistencia en MySQL, ETL en Pentaho Kettle, vistas, stored procedures y lógica de negocio en Kotlin.

---

##  Tecnologías Utilizadas

* **Lenguaje Principal:** Kotlin
* **Base de Datos Relacional:** MySQL / MariaDB (OLTP)
* **Data Warehouse & ETL:** Pentaho Data Integration (Spoon - `.ktr`)
* **Control de Versiones:** Git & GitHub

---

##  Estructura del Repositorio

* `/database`: Scripts de diseño relacional DDL (`schema.sql`), inserción de datos de prueba (`seeds.sql`) y lógica avanzada de base de datos (`procedures_and_views.sql`).
* `/docs`: Informes del proyecto, diseño de Data Warehouse, diagramas entidad-relación y carpeta `CONTENIDO FINAL` con artefactos ETL `.ktr` y consultas OLAP.
* `/src`: Código fuente backend en Kotlin (`Main.kt`) con la implementación de modelos de dominio y reglas de negocio.
